# Tarefas — Frontend

Pasta: `frontend/`. Stack: React + Vite, PWA.

- [ ] Criar o projeto Vite (React) em `frontend/`, com `base` configurado para GitHub Pages.
- [ ] Aplicar a paleta e a tipografia de `contracts/spec.md` (tokens CSS).
- [ ] Tela inicial: grade com os 20 temas.
- [ ] Tela de versículo: sorteio, referência, botões "Outro versículo" e "Favoritar".
- [ ] Tela de favoritos com remoção, usando `localStorage`.
- [ ] PWA: manifest, ícones 192/512 px, service worker para uso offline.
- [ ] Layout mobile first (acessos são majoritariamente por celular).
- [ ] Testes: fluxo tema → versículo → favoritar → remover.

Critério de conclusão: app roda localmente e os 4 fluxos funcionam no celular e no desktop.
